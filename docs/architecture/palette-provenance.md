# Palette provenance

This note traces the shared hue library to its Geonexus sources. The library retains the values and hue names from those sources. The immutable [Krees Sama review](https://github.com/esther-poniatowski/geonexus/blob/ed0c2ca5f6534271d9c3964cb3b63af5d14e6765/artifacts/mixture-input-encoding_poster_ccn2026/_reviews/sama-krees.md) recommends the retained azure and raspberry ladders.

The review affects the hue values only. Each consumer assigns its own semantic roles through its project palette.
